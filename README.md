# Roux Tutor

Mobile-first web app that teaches the Roux method for solving a Rubik's Cube. See [docs/PRODUCT.md](docs/PRODUCT.md).

## Getting started

```bash
cp .env.example .env.local   # fill in Supabase values
npm install
npm run dev                  # http://localhost:3000
```

## Checks

```bash
./init.sh   # install, typecheck, lint, test, build
```
